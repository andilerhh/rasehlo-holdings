DRIVEASSIST WEBSITE — FORMSPREE VERSION

FLOW: Home → Learners Driving Test Assistance → Registration → Formspree → Confirmation.

SETUP:
1. Create a Formspree account and New Form.
2. Copy the Form Endpoint, e.g. https://formspree.io/f/abcd1234.
3. In learners-test.html replace YOUR_FORM_ID with your real form ID.
4. Replace YOUR-DOMAIN.com in the _next hidden field with your real domain.
5. Deploy and test.

Formspree receives fields with name attributes. The form includes personal details, vehicle type, preferred location/date and additional information.

IMPORTANT: the form asks for ID number, date of birth and residential address. Confirm the business genuinely needs each field before going live and protect access to the resulting submissions appropriately.

This version uses Formspree for registration submissions. It does not create an availability calendar. An actual time-slot calendar can be added later if needed.
